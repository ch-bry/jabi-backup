# jabi-backup

Public homepage and privacy policy for **Jabi Backup**, the Google OAuth app that Bryan's
Mac mini backup (restic + rclone, `drive.file` scope only) uses to reach his own Google Drive.

- Homepage: https://ch-bry.github.io/jabi-backup/
- Privacy policy: https://ch-bry.github.io/jabi-backup/privacy.html

**No secrets here.** The OAuth client ID/secret and tokens live only in the Mac mini's rclone
config and in Bryan's password manager. Never commit them to this repo.

이 리포는 구글 앱 공개 조건(홈페이지·개인정보처리방침 주소)을 채우기 위한 두 페이지뿐이다.
백업 자체의 설명은 맥북 `~/Claude/_docs/macmini-backup.md` 에 있다.
