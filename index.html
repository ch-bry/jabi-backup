Jabi Backup

Jabi Backup is a private, single-user tool that copies Bryan's own files from his home Mac mini to his own Google Drive once a day. Files are encrypted on the Mac mini before upload, using the open-source tools restic and rclone. The tool only asks for the drive.file permission, which means it can see and manage only the files it created itself — nothing else in the Drive.

It is not offered to anyone else and has no other users.
